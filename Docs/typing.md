現在幫我把樹的自動生圖改變一下
首先，會給你一個 n
接下來會有 n - 1 個線段需要連接 ( 先是父節點，再來是子節點)

範例：
```
4
1 2
1 3
3 4
```

Tree 的部分就預設這個就好 ( 不用其他的建圖模式 )

再來是 圖

有兩個需要勾選 分別是 0based ? 和 有向圖?
預設無向圖 、 1 based

分為兩種
一個是直接給你 N 和 M 然後找出線段
例如

```
3 4
1 3
2 3
3 1
2 2
```


其中，有向圖的部分可能會有自環，請讓它顯示出來

第二種方式是給定 N ，然後接下來的 N 行會有給你一些點，會先給你一個 M 代表說這個線段一共有 M 個點與他連接

例如
```
4
0
1 2
3 4
4 1
```


其中，有可能會有一個點出現三個數字的情況 ( 樹 和給定線段見圖 ) 這是點的權重，請幫我把他的權重標出來 ( 包含自環 )
